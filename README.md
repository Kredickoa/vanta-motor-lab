# Vanta Motor Lab

A premium automotive detailing studio concept with a restrained editorial design. Built as a frontend portfolio project to explore product presentation, motion and visual storytelling.

[![Watch the demo](demo/preview.jpg)](https://github.com/Kredickoa/vanta-motor-lab/raw/refs/heads/main/demo/demo.mp4)

[Watch the demo video](https://github.com/Kredickoa/vanta-motor-lab/raw/refs/heads/main/demo/demo.mp4)

## Highlights

- A scroll-controlled car disassembly sequence rendered on canvas.
- Service cards, an automotive gallery and a demo enquiry form.

## Stack

React 19, TypeScript, Vite, Tailwind CSS, Motion, Canvas 2D and Lucide.

## Run locally

Requires Node.js 22.12+ and npm.

```bash
npm ci
npm run dev
```

Create a production build with `npm run build`, then run `npm run preview` to preview it.

Concept project, not a live commercial service. Any enquiry, cart or booking controls are demonstrations.
